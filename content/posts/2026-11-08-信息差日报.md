### 罗马混凝土会自愈

罗马万神殿的穹顶快两千年了还立着，没有一根钢筋，全靠混凝土。而今天很多混凝土建筑，几十年就开裂、剥落。这中间的差距，藏在一个一直被当成"瑕疵"的东西里。

古罗马混凝土里散布着一些白色小碎块，过去几十年都被当成搅拌不匀的杂质。2023 年 MIT 的团队发现，这些"石灰碎块"其实是罗马人"热拌"工艺刻意留下的：生石灰遇水放热，反应后形成的碎块，恰恰是混凝土自我修复的关键。一旦墙体开裂、雨水渗进去，碎块会重新溶解、再结晶，把裂缝重新堵上。再配上配方里的火山灰，罗马混凝土才能扛住两千年。

有意思的是，这种"坏了能自己补"的本事，现代人直到最近才真正看懂。科学家正在用更低温、更省能源的方式仿制它——两千年前的古人，无意中给今天的我们留了一份"如何造得经久耐用"的答案。

### Exa Monitors v2

> [!tip] 简介
> 定时在网页上搜索，一有结果就回调你的 agent，$2/1000 次。

Exa 本来就是"给 AI 做搜索"的语义搜索引擎，Monitors 是它加上的"定时器"：你设定一个查询，它按你定的节奏去搜网页，匹配到了就主动调你的 agent，把结果喂过去。用途写得很直白——找 leads、找候选人、找任何你一直在盯的东西。定价 $2/1000 次，便宜到可以批量挂。

它解决的是"搜索是拉取、而很多需求是等待"的错位。传统搜索是你主动去查；但"等某个新东西一出现就通知我"是另一类需求，过去要自己写爬虫或订 Google Alert。Monitors 把它做成了 agent 的原生能力，语义搜索 + 定时 + 回调，一条链全通。

边界在于它依赖 Exa 的搜索质量，且结果最终还是要你的 agent 去消化。适合已经在用 AI agent 做获客、研究、情报的人，不适合想要即拿即用、不想碰 agent 编排的人。

### LiveReview

> [!example] 简介
> 给 PR 打风险分，低风险的自动放行，高风险的才给工程师看。

大多数 AI code review 工具做的是"找出问题"，LiveReview 做的是"决定哪些根本不值得人看"。每个 PR 先被风险打分，风险最低的 30–50% 直接自动通过，剩下的才转给该看的工程师。它的依据是实打实的：参考了 Meta 内部的 AI 审查系统，据说把线上事故降了 50 倍、回滚降了 3 倍。32 条评论是今天榜单里讨论最热烈的，说明它戳中了一群被 review 压垮的团队的痛点。

技术上是三层叠加：LLM + 用事故数据训练过的 ML + 代码图谱分析，比单靠 LLM 的"猜"要稳一点。免费、可自托管，这两点对在意代码隐私的团队很关键。

边界要想清楚：自动放行意味着把"信任"外包给一个打分模型，出了事模型不背锅。适合 PR 量大、reviewer 严重不足的中大团队；小团队或安全敏感场景，还是得人工把关。

## 🧠 Big Think

### AI 会不会让生活失去意义

OpenAI 前几天说它最新模型在几周内解出了 100 多道数学家们啃了多年的题，数学家圈子里泛起一阵存在主义式的慌张。这件事被 Clay Routledge 和 Josh Hicks 拿来当引子，在[一篇调查解读](https://bigthink.com/science-tech/will-ai-make-life-less-meaningful-a-survey-finds-optimism-hinges-on-whether-humans-keep-control/)里问了一个更软的问题：AI 会不会让生活变得没有意义。

他们俩是 Archbridge Institute"人类繁荣实验室"的人，刚给 2000 多个美国人做了一轮调查。结果不难猜：56% 的人觉得 AI 更可能侵蚀意义，44% 觉得它更可能支撑意义。但真正让我停下来的是后面那个分组——人们怎么看 AI 的本质，几乎决定了他们怎么答这道题。

调查里 52% 的人把 AI 当成"一种全新的、终将走向自主的技术"，另外 48% 把它当成"和电、互联网一样的普通工具，始终由人掌控"。前者里只有 27% 相信 AI 会支撑意义，73% 觉得它会侵蚀；后者正好反过来，63% 觉得会支撑。这个翻转比任何人口学差异都大，而且在每个年龄段、性别里都成立。也就是说，决定一个人对 AI 是否乐观的，不是他几岁、做什么工作，而是他心里那台 AI 到底长什么样——是"我手里的锤子"，还是一个"会自己醒来的东西"。

我想起自己平时对 AI 的两种说法来回横跳。干活顺的时候，它就是个听话的锤子，帮我省时间；可一旦它写出我没想到的方案，我又会突然觉得它"有主意了"。这两种想象切换的那一刻，正是意义感的开关被拨动的地方。他们给的意义定义很朴素：人觉得自己"有分量、能造成差别"的时候，生活才有意义。AI 让人焦虑的，从来不是它会抢走多少活，而是它会不会变成那个"真正做决定、造成差别"的主体，把我们从自己的关系、工作、创作里挤出去。

收尾不悲观：技术几百年来一直在打断旧的意义感，但人是会适应的物种，制造 AI 的那种聪明劲儿，同样能帮我们找到新的方式去"有分量"。这倒提醒了我一句——也许我该少问"AI 会不会抢我的活"，多问一句：我还在往那些关系、项目、创造里"放自己"吗？放多少，是我自己决定的。

### 一张精确得"不像中世纪"的海图

1270 年前后，一种画满彩色放射线、标着密集港口名的航海图，毫无征兆地出现在地中海港口。它们叫波特兰海图（portolan chart），最老的一张是匿名的《皮萨海图》。诡异的地方在于：它太精确了——精确到几乎像今天的海图，而欧洲制图史上根本没有它的"少年期"，没有从笨拙到成熟的过渡，一登场就是成品。

荷兰测地学家 Nicolai 2014 年第一次说破这件事："我们只能一步一步倒推回去。"克罗地亚扎达尔大学的 Tome Marelić 接过了这句话，花了四年、发了五篇论文，用"制图测量分析"——把老地图数字化、钉上几百个可辨认的海角港口，再让计算机算它和现代地图差多少——做成了波特兰海图有史以来最细的一次法医式检查。

三个发现里，我最喜欢那个关于"一英里"的。波特兰海图统一用一种叫 miglio 的"波特兰英里"，约 1.25 公里，几百年没人说得清这个数打哪来。Marelić 找到了：2 世纪的托勒密算地球周长时少算了 29%，拿托勒密那个"偏小地球"沿地中海中纬度量 2 度经度，正好约 125 公里——也就是 100 个波特兰英里。换句话说，海图上那把尺子，是一千多年前一位天文学家算术错误的化石，被悄悄缝进了每张海图的刻度里。

还有一层更反直觉：这些海图其实不是 13 世纪水手的灵光一现，而是对更古老制图知识的"复制"。把一张图切成地中海、亚得里亚、爱琴海几块分别测量，精度几乎翻倍——这说明制图者是把几张现成老图拼起来的，而他们自己并不完全懂这些几何。海图统一的 -10° 偏角，过去都赖到"水手信了指南针的磁偏角"，Marelić 拿古地磁模型一对，发现根本不是磁针干的，而是两种更古老投影方式之间的一次妥协。

我在[这篇解读](https://bigthink.com/strange-maps/antique-sources-for-portolan-charts/)里读到的结局，是"没有失落的超级文明、没有外星飞船，只有古代知识被中世纪抄写员笨拙而诚实地传递"——它戳破了我心里那套"某个时代的技术来自一次天才顿悟"的叙事。很多"突然出现"的东西，背后是更早的知识被转手、拼装、重新包装。这比任何阴谋论都更值得回味。

### anthropics/skills

Anthropic 把"Agent Skills"这一整套格式开源了。所谓 skill，是给 coding agent 的"技能包"——一段带说明的提示词 + 脚本 + 模板，让 agent 遇到特定任务时按固定流程走。这个范式过去几个月在榜单上反复刷屏（google、mattpocock、cloudflare 都出了自己的 skills 仓库），Anthropic 作为概念的开创者，这次放出的官方仓库是整套生态的"母版"。

对开发者来说，这标志着"给 agent 写技能"正在变成和"写代码"并列的一项正经工作。以前调 agent 靠临场发挥，现在开始沉淀成可复用、可共享、可版本化的技能文件。今天 +390 星，说明这个范式还在持续发酵。

### ranxianglei/billion-context

一个上下文压缩插件，目标很野：让"长达一个月、几十亿 token 的单会话"能在 100K 的小上下文窗口里跑。思路是把历史对话实时压缩、分层存储，需要时再按相关性召回，而不是无脑把全文塞进窗口。

在"上下文越长越贵"的今天，这是"用聪明换便宜"的另一条路——不买更大窗口，而是把已有窗口用得更狠。TypeScript 写的，+191 星，还在早期，但方向戳中了很多长任务 agent 的痛点。
