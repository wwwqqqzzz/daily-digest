## 🧊 冷知识

### 本初子午线之争

世界上所有经度都以格林尼治为 0 度来量，这件事看着像天理,其实是 1884 年一场国际会议投票定出来的。在那之前,法国用巴黎天文台的子午线,美国用自己华盛顿的基准,各国海图各用各的"零度",航线一跨进别家水域就错位。

1884 年华盛顿国际子午线会议,41 国投票把格林尼治定为全球本初子午线。但法国那一票始终弃权,巴黎子午线又坚持用了几十年,直到 1911 年才松口。更讽刺的是,那根线其实并没有精确穿过英国格林尼治天文台屋顶的观测仪。

所以今天手机地图上那根 0 度垂线,背后不是某台物理计时器的精确结果,而是一场外交谈判敲定的。一门显得中立的科学,起跑线处也是政治选出来的——这条冷知识很适合在地图上点一根线的时候想起来。

### ngrok AI Gateway

> [!tip] One private gateway for every AI model.

ngrok 从做内网穿透起家,现在把"让私有服务安全暴露到公网"的手艺用到了 AI 路由上:一把 key、一个 URL,就能在 OpenAI、Anthropic 和自托管模型之间做调度,自带观测、访问控制和 fallback。

最独特的点在于**私有模型不用暴露到公网**。多数路由工具要你把私模型对公网开个口,ngrok 用自己那条私网链路,让私有模型和公有 provider 站在同一地址后面。钱包里挂着几个 API 又想留微调模型的团队,这个很对口。

价格也诚实:付费门槛明确,免费的额度聊胜于无。要走生产、不想自己运维网关的团队值得买;个人开发者用 litellm 这类方案可能更省。

## 🧠 Big Think

### 放慢不是落后,是训练

读到一个铁人三项运动员的故事,讲"想赢反而要先放慢"。Mark Allen 在 80 年代初把 "no pain, no gain" 当信条,训练却一次次把身体练垮:膝盖、跟腱、免疫力全线报警,成绩始终差一口气。

转折点是一位叫 Phil Maffetone 的教练。他的判断反直觉:Allen 一直在无氧区硬扛,得先退回有氧区的心率区间把底子打牢——一英里的配速从 6 分半降到 8 分半。让一个天天拼速度的铁人慢下来,心理上的煎熬远大于身体。Allen 照做了,几个月后在一场半铁赛里用几乎不变的心率跑出个人最好成绩,后来拿下六届铁人世界冠军。

我真正在意的是文末那句古老的拉丁语:**festina lente,慢慢地快**。罗马人把这句话刻在金币上,一只螃蟹配一只蝴蝶。放在今天的工作里,那种"回消息要快、交付要快"的直觉,恰恰常常牺牲掉真正需要沉淀的东西。慢不是停,是把油门踩得更准。这篇出自 Big Think 的 [pause-book 节选](https://bigthink.com/business/pause-book/),值得在赶进度的时候重读。

### 夜晚的光,是国家的体检单

> 一个卫星看出的铁血真相:夜间灯光几乎成了全世界最诚实的经济年报。

俄罗斯很会说 GDP 增长,可卫星拍到的夜间灯光在几年里收缩;朝鲜的夜光几乎全黑;伊朗的灯光一边被制裁一边暗下去。夜间灯光照出来的是电、工厂、夜班、港口吞吐——这一整套"工业体温",比任何报表都诚实,因为灯不会说谎。

最让我记住的分论点:灯光数据甚至能穿透刻意隐瞒。有人可以用关灯来藏工业减产,但灯光和电耗的关联是硬证据,造假空间很小。瑞典情报部门就用夜光图去校准俄罗斯的经济数据——官方口径和灯光走向对不上时,先怀疑报表。

这让我想到一个判断:真实信息往往不在一张光鲜的报表里,而在那些不被粉饰的角落。这篇来自 Big Think 的 [夜间灯光遥感解读](https://bigthink.com/strange-maps/nighttime-light-remote-sensing/),看完想立刻打开 NASA 的黑夜地球图。

### 地球上哪里的重力最强和最弱

一个平时没人注意的物理事实:**重力不是处处一样**。两极最强——因为离地心更近——赤道附近的高海拔点最弱。文章给出的两个端点:重力最强在北极,约 9.8337 m/s²;最弱在秘鲁安第斯山的瓦斯卡兰峰,约 9.764 m/s²,两地差约 0.7%。

原因是两层的:地球是个扁椭球,赤道更鼓,离地心更远;再加上地壳密度不均,同一个人在两地"称重"能差出小半公斤。对做工程的人这是个提醒:你以为恒定不变的 g=9.8,其实在地表上是随位置波动的。

读完我去查了下,这篇出自 Big Think 的天文物理专栏 [Start with a Bang](https://bigthink.com/starts-with-a-bang/gravity-strongest-weakest-earth/),作者 Ethan Siegel 的老规矩——把硬核物理讲成能摸到的常识。

### loopx

给长期运行的 agent 加一层"状态内核":可持久化的目标、自动唤醒、可执行的 todo 和证据日志。相当于把"跑一夜不乱"的 agent 做成一个可持久化的进程,适合 agent-loop 的团队——不用每次重启都重新灌一遍上下文。

开源、能自部署是加分。Coding agent 团队把它当胶水,补上"从记忆断电重启"这个老毛病。

### Addy Osmani / agent-skills

Chrome 老手 Addy Osmani 整理的"生产级工程技能"仓库:把 agent 从"能生成代码"拉高到"产出可维护、符合项目约束的代码"。不是一堆零散提示,而是可复用的工程规范——测试、重构、类型、边界——agent 拿到的约束越具体越好。
