### 牛顿的另一桩案子

我们记住的牛顿，是苹果、微积分和三大运动定律。但他人生的后半段有一份工作跟这些都没关系：1696 年他离开剑桥，去皇家铸币厂当督办，三年后升任厂长。

那时候英国的银币烂到了根上——有人把硬币边缘剪下一圈银子去熔，市面上流通的币轻得离谱。牛顿没把这当闲差。他亲自查案、审问、下狱，甚至跑到酒馆和牢房里套话，靠自己的司法权限把造假币的人一个个送上法庭。

最有名的是 William Chaloner，一个手艺极高、还反过头来公开指控牛顿的伪币制造者。牛顿花了很长时间收集证据，最后以叛国罪定了他。1699 年 3 月，Chaloner 在泰本刑场被绞死。有意思的是，这跟"科学家不该碰权力"的想象正好相反——牛顿做起这件事极其投入，近乎执拗，大概在他眼里，把假币清出去，和把错误的运动方程清出去是同一种洁癖。

> [!abstract] 简介
> 给 AI agent 一个长期记忆，不用你跑任何服务器。

Agent 的"失忆"是这一轮 AI 工具里最烦人的老问题：每开一个新会话，你得把它重新介绍一遍项目，换个机器又是从零开始。Memanto Cloud 想把这层记忆做成托管服务——`pip install memanto`、跑 `memanto`、浏览器里登一次，再 `memanto connect claude-code`（或 Cursor、Codex 等三十多个工具），之后 agent 跨会话、跨机器都能记得。

它最明确的取舍是"零基础设施"：不用 Docker、不用 API key、不用自己养一个向量库。同一条赛道里，Mem0、Zep、Letta 这些更偏"你自己搭、自己控"；Memanto 走的是相反的路线——把复杂度全包给云，你只留一个登录动作。对个人开发者和小团队，这个省事是真的省事。

代价也直白：你的上下文要进他们的云。如果记忆里是客户数据、内部代码库，这条线就得自己掂量；要自己掌控，还是得回到自托管的 Mem0 或 Letta。它更像"懒得搭、又要马上有记忆"的人的第一步，而不是终局方案。

### tinytldr

<div class="carousel">

</div>

> [!tip] 简介
> 别再让 agent 从零画，先做好模板，让它填格子。

"让 AI 做张图"最常见的结果是：每次出来的版式都不一样，你的品牌感全丢了。tinytldr 把这个流程倒过来——你在浏览器里先把模板设计好（纯 HTML、CSS 加一层 JSON 占位槽），之后让 Claude 或 ChatGPT 从任何来源（仪表盘、链接、发布说明、会议记录）把内容填进槽里，稳定输出图片、轮播或视频，同一个模板每次都长一样。还能接 Slack 做一轮评审再定稿。

它跟 Canva 模板、Gamma 这类"AI 一键生成"是两条路：后者的卖点是不用设计，代价是你说不清它会给你什么；tinytldr 的卖点恰恰是"设计由你定，agent 只负责填"。对一个天天要把同样结构的内容排版出图的人来说，这种可控比"惊喜"值钱得多。

边界也很清楚：模板本身你得先做对，槽位越严格越稳，但也越死板；MIT 开源，动手能力强的可以自己改。它本质上是个"给 agent 用的排版引擎"，不是创意工具。

### UndoGuard

<div class="carousel">
  <img src="https://ph-files.imgix.net/425a00ef-5857-4fa5-8b46-974bf3c3fb43.png?auto=format&w=1600&fit=max">
  <img src="https://ph-files.imgix.net/57e12f2e-130b-42ab-b6b0-b1dcc458dd7d.png?auto=format&w=1600&fit=max">

</div>

> [!example] 简介
> 给 agent 的每一次写操作配一个 Ctrl+Z。

现在大家都愿意给 agent 读权限，但一到"让它真的改东西"就犹豫——因为它可能把某个表、某个配置、某个客户记录改坏，而你根本不知道怎么退回去。UndoGuard 就卡在这个点上：它是一个回滚代理加 MCP server，蹲在 agent 和 API 之间，每次"会改状态"的调用之前先打一个快照并用 AES-256 加密存下来，出错时能回退单步，也能回退整个会话。

它的姿势很工程化：不要求你换框架，Claude、Cursor、LangChain、n8n、任何 REST API 都能套；免费沙箱给到每月一千次操作，先试门槛低。同类里，LiteLLM、Guardrails 这些更偏"拦不拦、准不准"的事前护栏，Temporal 那类是"任务级持久化"，UndoGuard 补的是"事后能撤回"这一块，思路更接近数据库事务。

需要留意的是它必须包在调用链里才生效——覆盖面取决于你把哪些 API 接进来；密钥和快照存在哪、谁能解，也是上线前要想清楚的。当 agent 开始动生产数据，"能不能撤"这件事的分量，迟早会超过"跑得多快"。

### 男人是不是为打架进化的

有一个画面我一直记着：宾州州立大学的人类学家 David Puts 还是研究生的时候，坐在商场美食广场啃汉堡，听见背后两个男人说话，声音低得反常。他回头一看，不远处站着一位年轻好看的女性。他后来把这件事做成了博士论文——男人为什么会有这么低的嗓音。

顺着这条线，他和学生 Saeed Koohgard 今年出了一篇综述，题目直接叫《最致命的灵长类》。大意是：在人类男性的演化里，"男人之间为了配偶而竞争"这件事被低估了。支撑它的数字听起来分量很足——过去十五万年里，能繁衍的女性数量大约是男性的三倍；八万到两万年前的尼安德特人与早期现代人遗骸中，男性头部受创的比例约是女性的六倍；四个地区跨二十年的凶杀数据里，无亲缘关系的男性杀死彼此的概率，是无亲缘关系女性的二十七倍。还有一个我很在意的细节：Puts 早年做实验时发现，低嗓音对"女性觉得他有吸引力"的影响其实不大，但对"另一个男人判断他好不好惹、打不打得过"的影响，是前者的十五倍。

我读到"十五倍"的时候停了一下。它把一件被我们当成魅力的事翻了过来，变成威胁。低嗓音、络腮胡、更多的肌肉——这些被叫作"地位徽章"的东西，作用是不打而屈人之兵。

可我没办法就这么接受。普林斯顿的人类学家 Agustín Fuentes 的评价很硬：这套想法"主要由演化心理学家支持，多数人类学家根本不认"，它只是"非常小的一片、而且很有偏向的视角"。这句提醒对我有用——一个解释能自洽，不代表它覆盖了全部。暴力到底有多少写在基因里、多少写在处境里，我大概一辈子也等不到终稿。能做的大概是：看到"天性如此"的说法时，先问一句，这是证据，还是有人正好想要的那个结论。这篇综述的原题是 [The deadliest primate](https://www.sciencedirect.com/science/article/abs/pii/S0047248426000928?via%3Dihub)，我把它留着，慢慢读。这类"演化心理学和人类学各说各话"的争论，Big Think 的 [Mind & Behavior](https://bigthink.com/mind-behavior/) 栏目里还有不少，我打算顺着一篇篇看下去，不急着站队。

### 钋光晕与年轻地球

科学里最动人的一件事是：只要有哪怕一条站得住的证据跟我们对世界最深的想法冲突，我们就得改。默丘里轨道的异常推翻了牛顿引力，能量量子化催生了量子物理。所以每次冒出"这和主流说法矛盾"的观察，都值得认真看。

一位读者写信给伊桑，说朋友发给他一份材料，标题是《钋放射性光晕：反对数百万年的有力证据》，他不知道怎么跟朋友解释这为什么站不住。伊桑的处理方式我很喜欢：他先把对方的三段论一条条摆出来，逐条对照地质学和核物理的共识。前两条其实大半是对的——铀衰变链确实留下同心圆环，钋同位素确实只活几天。真正的破绽在最后一步：那些"孤儿"钋光晕，不需要什么"几千年前衰变突然加速"的洪水剧本，只要想想镭之后是氡——一种气体，它会在岩浆房里上升、钻进岩石裂缝，冷却到一定程度再留下痕迹。岩石类型、温度、冷却速度，本身就能解释一到三层还是五层圆环。

让我停下来的是伊桑最后那段话。他说，这类说法的重点从来不是"我发现了反常"，而是"去找一条听起来很厉害、能让外行相信主流科学错了的推理"。大多数正经科学家不熟悉它，公众要弄懂它得先啃一大堆背景，而它本身一句话就能讲完——这就是布兰多里尼定律：驳倒一句胡话要的能量，比造出它大一个数量级。

我有点被戳到。以前看到朋友转发那种"其实地球只有几千年"的长图，我第一反应是找一句能一秒钟噎回去的话，找不到就有点恼火，甚至隐隐觉得"是不是我错了"。现在我想练习另一种耐心：我可以暂时答不上来，但"我三十秒内驳不倒它"跟"它是对的"是两回事。真正要守的不是面子，是那套愿意被证据改、也愿意花力气去核的笨办法。这篇问答叫 [Do polonium radiohalos support a young Earth?](https://bigthink.com/starts-with-a-bang/polonium-radiohalos-young-earth/)，值得存下来，下次有人再发那样的图，我知道从哪儿讲起。
