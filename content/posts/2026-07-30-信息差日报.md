### 紫色曾是身份的货币

今天我们穿紫色衣服、用紫色设计元素，觉得稀松平常。但在整个古代世界，紫色比黄金还贵。

最早的紫色染料来自地中海的一种骨螺（Murex brandaris）。提取过程极其残忍：上万只海螺碾碎后暴晒，分泌物在阳光下从黄色变成紫色，一克染料需要上万只海螺。所以紫色布料的价格是黄金的等重甚至更贵——罗马帝国的元老院甚至立法规定只有皇帝能穿全紫色的托加袍。这就是"born in the purple"（生于帝王之家）的由来。

有意思的转折发生在 1856 年。18 岁的英国化学系学生威廉·珀金想合成奎宁（治疟疾），失败了却得到一种紫色液体——苯胺紫（mauveine），人类第一种合成染料。紫色一夜之间不再是奢侈品。珀金 35 岁就退休了，用专利费建了豪宅。

到今天，"紫色门槛"这个概念还在——公司内部"需要穿紫色"才能进入的圈子，说的就是古代只有皇帝能穿的那个紫色。

### Prelint: Prevent product drift in AI-written code

> [!tip] 简介
> AI 写的代码审查层——不查语法错误，查"产品漂移"：你的 PR 偏离了当初的架构决策和业务方向

AI 写代码的速度是人的 10 倍，但它写的代码往往在实现层面完全正确，在产品层面却偏离了方向——选了不同的库、用了不同的架构模式、违背了 ADR（架构决策记录）里的约定。Prelint 干的事就是用 AI 查 AI，在 merge 之前拦截这种"产品漂移"。

团队自述，用了多个 AI review 工具的团队中，大约 40% 在 merge 前修复的 issue 是 Prelint 抓出来的——这个数字很有意思，说明现有工具（CodeRabbit、Graphite 之类）在语法和逻辑审查上已经不错了，但在"感知意图"层面还有空白。竞品方面，Ellipsis 偏 bug 修复，Cubic 偏代码审查 UI，Prelint 的差异点是审查维度：不是"这段代码对不对"，而是"这段代码应不应该出现在这里"。

免费版可用，有 $100 额度赠送。适合 AI 代码占比高的团队——如果你还在手动审查每一行 AI 生成的代码，可能更需要 Prelint 来分层。

### Task Monki: Run coding agents through full dev process

> [!abstract] 简介
> 开源桌面应用，管理多个 coding agent 从任务到 PR 的完整流程

Task Monki 解决的问题很具体：一个 Claude Code 实例只能在一个任务上跑，但真实项目通常是多个 task 并行推进。Task Monki 让你同时跑多个任务，跟踪每个 agent 的进度，预览结果，甚至让 agent 之间互相 review 和讨论。

### MemoryCustodian: Repo-native memory for coding agents

> [!info] 简介
> 把 aging agent 的项目记忆存成 Markdown 文件放在仓库里，跨 session 持久化

每次新开一个 Claude Code / Codex session，agent 都不记得上次为什么做那个架构决策——这是所有 coding agent 用户的痛点。MemoryCustodian 的方案很简洁：用 Markdown 文件记录项目决策、约束、被否定的方案，放在 repo 里，用一个 manifest 按需加载。

免费，开源，本地优先。

### AI 揭示了植物和真菌的隐藏智能

有一个比喻让我印象很深：植物的根系神经网络，本质上跟哺乳动物的大脑没有太大区别——只是它用生长速度和化学信号代替了神经元放电。

大意是神经生物学家 Paco Calvo 用 AI 工具分析了植物根尖的电信号，发现它们对刺激的反应模式跟动物神经元的反应非常相似。植物在感知到压力时，根尖会释放谷氨酸——同样也是人脑中用来传递信号的神经递质。更有趣的是，Calvo 团队用机器学习模型解码了植物的电信号，"读"出了它们对不同刺激的"反应"——比如触摸、光照变化、水分短缺。

以前我对"植物也有意识"这类说法一直是持保留态度的，总觉得这是在拟人化。但看完这个研究的框架后，我的困惑变了：不是"植物有没有意识"，而是"信息处理系统需要什么才算意识"。如果根系网络的信息处理模式跟神经网络同构，那它凭什么不算？

真菌的地下网络——菌根网络（Wood Wide Web）——真菌通过化学信号和电脉冲在树木之间传递营养和警告。AI 正在帮我们"翻译"真菌的语言：用傅里叶变换分析菌丝的电信号模式，发现它们有类似语法结构的信号序列。以前我们觉得这是隐喻，现在 AI 告诉我们这可能是字面意义的真实。

[AI 如何揭示植物和真菌的隐藏智能](https://bigthink.com/science-tech/how-ai-is-revealing-the-hidden-intelligence-of-plants-and-fungi/)

### "野蛮民族"的神话有一个古老的起源

人择原理——简单说就是"为什么我们看到的世界是这个样子，因为如果它不是这样我们就不在这里观察"——最近被科学哲学家 Stephen Wolfram 重新捡起来讨论了。

Wolfram 跟物理学家 Jonathan Gorard 做了一篇访谈，大意是在说人择推理在物理学的历史上一直被当作一种最后手段：当地球上的物理常数被调节到可以产生生命，有人会说是巧合，人择原理说"好吧，如果常数不一样我们也不会在这里讨论它"。但这个推理本质上是一种循环论证，Wolfram 主张用计算等价原理（computational equivalence）来替代它——把"为什么宇宙是可理解的"这个问题从哲学层面推到了计算层面。

我特别在意的是他们对人择推理的批评：它本质上不能预测任何东西，只能解释已经观察到的事实。这在物理学里是一个非常危险的倾向——你永远可以用人择原理"解释"为什么某个常数恰好是这个值，但实际上这个解释没有信息量。跟他们观点类似的哲学家 L.A. Paul 把这类推理叫做"结构同义反复"——表面上在解释，实际上在重复前提。

[对人择推理以及《科学：一个新的黄金时代》报告的批评](https://bigthink.com/starts-with-a-bang/honest-inside-science-new-golden-age/)
