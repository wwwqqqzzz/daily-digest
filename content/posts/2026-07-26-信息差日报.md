## 🧊 冷知识

### 一天为什么是24小时

如果你以为是地球自转决定的，那只说对了一半。真正决定这个数字的，是几千年前苏美尔人的手指——准确地说，是他们数指节的方式。

苏美尔人用拇指去点同一只手的其余四根指节，每根手指三段指节，一共12。所以他们不数10，数12。这套**十二进制（duodecimal）**后来影响了整个两河流域文明。更关键的是，他们把12乘以5（另一只手的五根手指）得到了60，发展出了**六十进制（sexagesimal）**。

我们今天用的24小时制就是从这儿来的：苏美尔人把一天分成12个"白天小时"和12个"夜晚小时"（因为夜晚用星星计时更方便）。而每小时60分钟、每分钟60秒，也是六十进制的遗迹。

有意思的是，人类历史上尝试过多种十进制时间系统（法国大革命时期就推行过十进制日历，一天10小时，每小时100分钟），但全都没活下来。几千年过去，我们还在用苏美尔人手指头的计数方法生活。

### Fedica 2.0

> [!tip] 简介
> 一站式社交媒体发布与增长工具

Fedica 2.0 的定位很聪明——不是又一个发布排期工具，而是一个跨平台社交账号管理中心。它覆盖 X、LinkedIn、Bluesky、Pinterest、Mastodon，更重要的是提供了一个 Chrome 扩展，让你在刷任何一个平台时可以直接把内容回传到 Fedica 统一管理。当前社交媒体已经从"一个广场"变成了"一堆社区"，每个平台的算法和文化都不一样，手动分发确实越来越累。Fedica 直接解决了这个痛点。

同类产品里，Buffer 和 Hootsuite 更重企业级团队协作，Later 偏视觉内容，Fedica 在个人创作者和中小团队之间找到了一个平衡点。支持 Chrome 扩展这一点尤其实用——看到一条好内容，不用切工具就能直接保存到发布队列。

### Pushary

> [!example] 简介
> 在锁屏上审批 AI 请求

这个想法很直接但实现得漂亮。当 Claude Code、Codex、Cursor、Hermes 等 AI agent 在执行过程中需要权限或问问题时，Pushary 把那个"是/否"推送到你的手机锁屏上。你不需要打开电脑，扫一眼就能点同意，agent 继续跑。它支持按工具设置自动审批策略，还有完整的审计记录。

### Fluree AI

> [!abstract] 简介
> 为 AI agent 提供可信的数据上下文层

Fluree 之前是做知识图谱数据库的（被 Gartner 评为 Cool Vendor），这次推出的 Fluree AI 是一个 serverless 知识图谱平台，核心卖点是"让 AI agent 不再胡编数据"。它本质上是一个智能数据层——你连上企业的各种数据源，Fluree AI 自动分类、建立关联，然后 agent 可以像查 MCP 工具一样查询它，返回的是经过治理的真实数据，不是 LLM 生成的幻觉。原生支持 MCP 协议，Claude、Cursor 可以直接查询。

跟传统的向量数据库（Pinecone、Weaviate）比，Fluree AI 不只是存 embedding，而是维护了一个完整的语义图谱。跟 LangChain 的 RAG 方案比，它不需要你写一堆管道代码。局限性在于上手门槛——知识图谱的概念本身就需要学习成本。

### Heard

> [!info] 简介
> 给 Claude Code 和 Codex 装上声音

Heard 是一个 macOS 语音层，连接 Claude Code、Codex 和 Cursor，把它们的输出转成自然语言语音。最有意思的设计是"并行 agent 的项目级摘要"——如果你同时跑了五个 agent 在干活，Heard 不会让五个终端同时说话，而是汇总成"A 在改样式、B 在修 bug、C 需要你确认一个东西"。支持手机配对，离开电脑也能听进展。

### ADE

> [!tip] 简介

## 🧠 Big Think

### 美国文学，一幅地图

有一个大胆的尝试：把美国文学史上所有重要作品画在同一张地图上。不是按照作家出生地来定位，而是按照**故事发生的地点**。福克纳的约克纳帕塔法县在密西西比，凯鲁亚克的《在路上》横跨整个美国东海岸到西海岸，马克·吐温沿着密西西比河画出了一条线。

最动人的可能是那些"空的"地方——大平原和落基山脉的某些区域，几乎没有任何文学作品标注。这本身就在说一个故事：文学的版图不是均匀覆盖的，它跟着人走，跟着历史走，跟着出版业走。纽约和波士顿密密麻麻，中西部则是零星的点。

我特别在意的一点是，这张地图让人重新意识到"地方"在文学里的分量。现在读东西太快了，很多时候忘了主人公脚下的土地其实是书里最重要的角色之一——福克纳的南方如果没有那股闷热的、压抑的空气，就不是福克纳了。把文学变成一张视觉地图，像是在说：故事从来不是凭空发生的，它们都有泥土味。

链到原文：[A Map of American Literature](https://bigthink.com/the-past/a-map-of-american-literature/)

### 休假的价值不在效率，在人性

Big Think 上在推一篇关于休假的书摘，观点跟主流生产力叙事完全相反。不是"休假让你回来更高效"——那还是把休假工具化了——而是"休假的价值在于暂时脱离工作身份，恢复作为一个人的感受"。

大意是说，当我们把自己完全等同于"做某件事的人"（程序员、经理、创业者），休假就成了对身份的威胁——不工作的时候你是谁？这种焦虑让很多人即使休假也在回消息。书里把休假重新定义为"一段不产出任何东西、也不需要用产出衡量价值的时光"。不是为了身体恢复（那是医疗），也不是为了更高效地投入下一轮工作（那是投资），就是为了让"你不是你的工作"这个事实变得真实。

读完后我想起一个自己观察到的现象：真正休过假的人，回来之后对"哪些事情真的重要"的判断会发生变化，但这个变化通常持续不了两周。系统会把你拉回原来的轨道。也许休假的真正意义不是改变系统，而是制造一个"可被回忆的缺口"——让你知道还有另一种活法的存在。

链到原文：[The Value of Vacation](https://bigthink.com/neuropsych/vacation-value-not-efficiency/)
