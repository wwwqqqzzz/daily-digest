## 🧊 冷知识

### 香蕉是放射性的

一根香蕉含有微量的钾-40，一种天然放射性同位素。每根香蕉大约含 15 克钾，其中约 0.00117% 是钾-40，衰变时会释放 β 射线和 γ 射线。

这个量极其微小——吃一根香蕉所受的剂量约为 0.1 微西弗，相当于你坐在电脑屏幕前几个小时的辐射量。物理学家甚至发明了一个单位叫「香蕉等效剂量」（Banana Equivalent Dose），用「吃了几根香蕉」来衡量其他辐射源的强度，让抽象的数字变得好懂。

有意思的是：你每天喝的水、吃的米饭、砖墙、甚至人的身体本身都有微弱的放射性。辐射无处不在，香蕉只是其中最出名的那个科普梗。下次有人说「辐射很危险」，你可以拿香蕉打个比方。

### Rippling: AI Spend Console

> [!abstract] 简介
> 把 AI 支出和业务成果连在一起的控制台

AI 开支现在是公认的黑洞，但多数公司只知道「账单在涨」，说不清钱花在哪、换来什么。Rippling 把这个做成一个针对 AI 花费的审计台：按供应商、模型、甚至某个员工拆解成本（比如 Claude、Cursor），然后把花费和 GitHub 的产出数据——PR 数量、代码修订次数——拼在一起看。

这其实是把原本模糊的「AI 投资回报」具体化。它火起来的原因不只是监控，而是给了 Finance 和 Engineering 一个共同的坐标系：以前工程师闷头加 buffer，财务只知道月底掏钱，两边没有对齐的语言。产品免费就能开始用，不强制绑定 Rippling 订阅——降低了尝试门槛。

### Superlog Responder

> [!example] 示例
> 免费、开源的 AI 修 bug 代理

一个直接插在你已有的 Sentry/Datadog Slack 频道里的 AI agent——不用再装新的「遥测」。每当一个告警出现，它会跑一遍完整上下文去调查，过滤掉噪音，对真正的问题直接在帖子里回复根因、证据，甚至是一段可合并的 PR。

### Annotate

> [!tip] 提示
> 用屏幕录制生成 AI 提示词

一个本地优先的 macOS 应用，把录屏、标注和语音变成可以直接喂给 Cursor/Claude/Codex 的提示词。写长提示词但 agent 还是猜错，因为静态截图抓不住动作、表单输入和实时 UI 反馈——录下来加标注再交给 agent，它就能「亲眼看到」你要修的东西。

产品的聪明之处在于「把调试过程本身变成提示词」。本地运行、免费、数据不出设备，是 vibe coding 工具链里一个少见的「给 agent 看视频」的方向。

### Website to Markdown API

> [!info] 说明
> 把任意网站变成 LLM-ready 的 Markdown

一个开发者工具，输入 URL，输出干净的结构化 Markdown——专门为「让 LLM 吃网页」设计。RAG、爬虫、agent 工具链里把网站转文本，通常要自己踩坑处理反爬、去导航、抽正文，这个 API 把它封装成一次调用。

它踩在当下 agent 生态的痛点上：AI agent 要读网页，但网页 HTML 对它是噪音，需要中间这层「翻译」。对做 agent 项目、搭知识库的人，省掉的是最烦的清理环节。

## 🧠 Big Think

### 宇宙似乎是无限的？

138 亿年前发生了那个最重要的事件：暴胀结束，炙热的大爆炸随之而来。到今天，我们能看到的部分已经膨胀成一个以我们为中心、半径约 460 亿光年的球。但让我停顿的是：这个巨大的数字，其实只是「我们目前能观测到的上限」，根本不是「宇宙有多大」。

天文学家测量了我们所在区域的时空曲率——它平得不能再平，偏差不超过 1/400。这个数字一旦成立，三个维度一乘（400³），就逼出一个结论：在我们观测不到的那部分，至少还有一个体积比可见宇宙大了 6400 万倍的空间。即使如此，那也仍然是有限，而不是无限。

真正可能把它推成无限的是「永恒暴胀」：在最开始，宇宙在极短的时间里指数膨胀，而只要这个膨胀在某处还在继续，就会不断孕育出新的「大爆炸」——也就是一连串彼此不相连的宇宙。膨胀到底持续了多久、是不是从无限久之前就开始、有没有可能真的无限大——这三个问题决定了「无限」是否成立，但我们恰恰无法观测到答案。物理学家诚实得让人放心：它不说大话，只承认「这部分我们没法知道」。结论大概是一句话：宇宙很可能比你想象的大得多，但恐怕还不是无限。

这篇天文科普叫 [Is the Universe truly infinite in size?](https://bigthink.com/starts-with-a-bang/universe-infinite/)，同一栏目里那篇问「第一生命会在夜空中看到什么」的 [问伊桑](https://bigthink.com/starts-with-a-bang/first-life-see-night-sky/) 也适合睡前读。我最近在盯我们自己的产品数据时也常犯这个毛病：把「我能测到的」当成「事实的全部」。可观测宇宙的教训是，测不到不等于不存在，只是说明这套工具到头了。

### 扮演 Steve Urkel 的那个人

在 Big Think 的 Perception Box 访谈栏目里，演员 Jaleel White——就是《欢乐满屋》里演 Steve Urkel 的那个孩子——回看了自己童星入行的那段路。他记得小时候坐在开公交车的爸爸身边，很自豪地对着车厢里的陌生人说「我爸爸是这辆车的司机」。

然后他讲了一个把自己撞到的点：他很早就在镜头前表演，这种早熟让他整个人变得「极度敏锐地在意别人怎么看自己」——不是在意演得好不好，而是在意「别人眼里的我」是什么样。这种对外界目光的依赖一路延伸：成名之后，他回想事业上那些关口，并没有真正握住方向盘，更多是「脚一只门里、一只门外」，心里其实还是把决定权交了出去。

更击中我的是他描述事业低谷的一段：一部剧被砍之后，他变得比本性还孤僻得多，并且承认「我的身份太重地拴在工作上了」。这句话我一直记得。一个人把「我是谁」完全押在事业和外界的框架上，事业稍微晃一下，整个人就跟着晃。他甚至很诚实地谈过自己作为单亲爸爸，为了养家会接活继续演，而不是等着挑「更有分量」的角色。

这段访谈叫 [Jaleel White on the greatest perspective shift of his life](https://bigthink.com/perception-box/jaleel-white-on-the-greatest-perspective-shift-of-his-life/)。对我这种很容易把自我价值挂在「我做的事被认可了吗」上的人来说，它几乎是一面镜子。我想起最近每次跟人讲完方案，第一反应不是方案本身好不好，而是对方脸上的表情——这种对外界目光的敏感，大概也需要一点一点迁回到自己身上。
